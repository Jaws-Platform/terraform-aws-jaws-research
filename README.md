# terraform-aws-jaws-research

Terraform modules for research workloads on AWS: ephemeral EC2 task runners for CI jobs and append-only S3 dataset buckets

The modules are on their way: this is the initial scaffold. Once the first
version is released they are published on the
[Terraform Registry](https://registry.terraform.io/modules/jwallace145/jaws-research/aws/latest)
as `jwallace145/jaws-research/aws`.
